# Entr.act

Site vitrine du salon de coiffure **Entr.act**, 7 rue de l'Hôtel de Ville,
85100 Les Sables-d'Olonne.

En ligne : <https://florian-teis.github.io/entract/>

HTML, CSS et JavaScript, sans dépendance ni étape de compilation.
Le dossier se dépose tel quel chez n'importe quel hébergeur.

```
index.html          la page
assets/css/         la feuille de style
assets/js/          les comportements
assets/img/         logo, photos, images d'attente des vidéos
assets/video/       les films (MP4, H.264, sans son)
```

Réservations : [Planity](https://www.planity.com/entract-85100-les-sables-dolonne-f8d)
